Dark Descent 選單修復過程 - 主要錯誤型態整理
================================================================

修復過程中遇到的主要錯誤型態


1. CS0246 - 類型或命名空間找不到
---------------------------------
錯誤訊息：
  找不到類型或命名空間名稱 'DarkDescentSetupWizard' 
  (是否遺漏了 using 指示詞或組件參考?)

原因：
  - 編輯器腳本之間的循環依賴
  - 在同一編譯單元中使用 typeof() 引用尚未編譯的類

解決方案：
  改用檔案檢查而非類型檢查


2. Assembly Reference Error - 組件參考錯誤
-----------------------------------------
現象：
  選單項目無法顯示

原因：
  - Editor 腳本引用 Runtime 腳本但沒有正確的 Assembly Definition
  - 缺少 .asmdef 文件來定義組件間的依賴關係

解決方案：
  創建 Assembly Definition：
  - DarkDescent.Runtime.asmdef (Scripts 資料夾)
  - DarkDescent.Editor.asmdef (Editor 資料夾，引用 Runtime)


3. 類名錯誤 - Type Name Mismatch
--------------------------------
錯誤代碼：DarkFallController
正確代碼：DarkDescentController

原因：
  類名拼寫錯誤，導致：
  - GetComponent<>() 找不到組件
  - AddComponent<>() 嘗試添加不存在的類型
  - 編譯時無法解析類型

影響：
  編輯器工具無法正常編譯，選單項目不顯示


4. MenuItem 未註冊
------------------
原因可能：
  - 類包含編譯錯誤
  - 缺少 Assembly Definition
  - 類名與檔名不匹配
  - EditorWindow 類未正確繼承

驗證方法：
  - 檢查 Console 視窗是否有錯誤
  - 確認 .cs 和 .cs.meta 文件都存在
  - 使用 AssetDatabase.Refresh() 強制刷新


錯誤修復優先順序
================
1. 編譯錯誤 → 先修復所有 CS 開頭的編譯錯誤
2. Assembly Definition → 確保組件參考正確
3. 類名一致性 → 確保類名與實際檔案匹配
4. 強制刷新 → 使用 Unity 的刷新工具重新掃描


修復結果
========
所有錯誤已修復，Dark Descent 選單應包含以下項目：
1. 🌌 自動設定場景
2. 🔍 驗證場景配置
3. 🏥 專案健康檢查
4. ⚡ 強制重新匯入資源
5. 📋 顯示專案資訊
6. 🔧 檢查選單項目（新增）
