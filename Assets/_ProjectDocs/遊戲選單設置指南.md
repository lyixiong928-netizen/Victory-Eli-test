# 🎮 遊戲選單自動化設置指南

## 📋 系統架構

這個選單系統使用以下組件協同工作：

1. **UIPanel** - 基礎面板類（處理顯示/隱藏、動畫）
2. **UIPanelManager** - 面板管理器（協調多個面板）
3. **GameMenuController** - 遊戲選單控制器（自動化邏輯）

---

## 🔧 在 Unity 中設置步驟

### 第一步：創建 Canvas 層級結構

在 **trialcanvasdbgun** 場景中，創建以下層級：

```
Canvas (畫布)
├── MenuManager (空物件 - 掛載 UIPanelManager + GameMenuController)
├── MainMenuPanel (掛載 UIPanel)
│   ├── Title (Text: "遊戲主選單")
│   ├── StartButton (Button: "開始遊戲")
│   ├── SettingsButton (Button: "設定")
│   └── QuitButton (Button: "離開")
├── SettingsPanel (掛載 UIPanel)
│   ├── Title (Text: "設定")
│   ├── VolumeSlider (Slider: 音量控制)
│   ├── FullscreenToggle (Toggle: 全螢幕)
│   └── BackButton (Button: "返回")
└── AboutPanel (可選 - 掛載 UIPanel)
```

---

### 第二步：設置 UIPanel 組件

為每個面板設置 UIPanel：

#### MainMenuPanel 設定
```
面板名稱: "MainMenu"
開始時顯示: ✓ (勾選)
使用動畫: ✓ (勾選)
淡入速度: 2
```

#### SettingsPanel 設定
```
面板名稱: "Settings"
開始時顯示: ✗ (不勾選)
使用動畫: ✓ (勾選)
淡入速度: 2
```

---

### 第三步：設置 MenuManager

在 **MenuManager** 物件上：

1. **添加組件**: `UIPanelManager`
   - 拖入所有面板到 `All Panels` 列表
   - 勾選 `Only One Active` (同時只顯示一個)
   - 勾選 `Esc To Close All`

2. **添加組件**: `GameMenuController`
   
   **選單面板引用：**
   - Main Menu Panel: 拖入 MainMenuPanel
   - Settings Panel: 拖入 SettingsPanel
   - About Panel: 拖入 AboutPanel（可選）

   **主選單按鈕：**
   - Start Game Button: 拖入 StartButton
   - Settings Button: 拖入 SettingsButton
   - Quit Button: 拖入 QuitButton

   **設定面板按鈕：**
   - Back Button: 拖入 BackButton
   - Volume Slider: 拖入 VolumeSlider
   - Fullscreen Toggle: 拖入 FullscreenToggle

   **場景設定：**
   - Game Scene Name: 輸入要載入的場景名稱（例如："GameScene"）
   - Show Main Menu On Start: ✓ (勾選)

## 🎯 自動化功能

### ✅ 自動初始化
- 系統啟動時自動顯示主選單
- 自動載入儲存的音量和全螢幕設定
- 自動連接所有按鈕事件

### ✅ 面板切換動畫
- 所有面板支援淡入淡出效果
- 使用 CanvasGroup 控制透明度和互動

### ✅ 鍵盤控制
- **ESC 鍵**：
  - 在設定面板 → 返回主選單
  - 在主選單 → 離開遊戲

### ✅ 設定自動儲存
- 音量調整自動儲存到 PlayerPrefs
- 全螢幕設定自動儲存
- 下次啟動自動載入

2. Normal Color: 白色
3. Highlighted Color: 淡藍色
4. Pressed Color: 深藍色

## 📝 快速測試

1. 執行場景（Play）
2. 測試主選單按鈕：
   - ✓ "開始遊戲" - 載入遊戲場景
   - ✓ "設定" - 切換到設定面板
   - ✓ "離開" - 結束遊戲
3. 在設定面板：
   - ✓ 調整音量滑桿
   - ✓ 切換全螢幕
   - ✓ "返回" - 回主選單
4. 按 ESC 鍵測試快捷鍵

## 🔍 常見問題

**Q: 按鈕沒有反應？**
A: 檢查 Canvas 是否有 GraphicRaycaster 組件，EventSystem 是否存在於場景中。

**Q: 面板沒有淡入淡出？**
A: 確保面板物件上有 CanvasGroup 組件，且 UIPanel 的 `useAnimation` 已勾選。

**Q: 音量設定沒有儲存？**
A: 檢查是否正確連接 VolumeSlider 到 GameMenuController。

**Q: 場景載入失敗？**
A: 確保在 Build Settings 中添加了目標場景。

## 🚀 進階擴展

### 添加更多面板
```csharp
// 在 GameMenuController 中添加：
public UIPanel creditsPanel;

public void OnShowCredits()
{
    mainMenuPanel.Hide();
    creditsPanel.Show();
}
```

### 添加音效
```csharp
public AudioClip buttonClickSound;
private AudioSource audioSource;

void OnButtonClick()
{
    if (audioSource != null && buttonClickSound != null)
    {
        audioSource.PlayOneShot(buttonClickSound);
    }
}
```
