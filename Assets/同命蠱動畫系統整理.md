## 🎯 最終目標：同命蠱三張圖跑動畫

### 快速設定步驟

#### **方法 1：一鍵完成（推薦）**
1. Unity 選單 → `DarkDescentDemo → 自動化創建 → 完整動畫角色` 或按 `Ctrl+Shift+A`
2. 選中創建的 AnimatedCharacter
3. 按 `Ctrl+Shift+P` 設定並播放動畫
4. 按 `Ctrl+Shift+V` 設定視覺效果（移除粉紅色方形）

#### **方法 2：創建三個角色同時顯示**
1. Unity 選單 → `DarkDescentDemo → 同命蠱 → 設定三個角色顯示`
2. 自動創建：骷髏死神、被詛咒的女子、黑暗生物

## 🔧 選單功能說明

### **DarkDescentDemo → 自動化創建**
| 功能 | 快捷鍵 | 說明 |
|------|--------|------|
| 完整動畫角色 | Ctrl+Shift+A | 創建物件 + SpriteRenderer + 動畫組件 + 自動設定 |
| 僅空物件 | - | 只創建空的 GameObject |
| 為選中物件添加動畫組件 | - | 為現有物件添加動畫功能 |

### **DarkDescentDemo → 動畫控制**
| 功能 | 快捷鍵 | 說明 |
|------|--------|------|
| 設定並播放動畫 | Ctrl+Shift+P | 自動設定精靈幀並開始播放 |
| 切換到快速動畫 | - | 15 FPS 快速播放 |
| 切換到待機動畫 | - | 8 FPS 正常速度 |
| 暫停/繼續 | - | 切換播放狀態 |

### **DarkDescentDemo → 同命蠱**
| 功能 | 快捷鍵 | 說明 |
|------|--------|------|
| 快速設定視覺效果 | Ctrl+Shift+V | 指定精靈圖片，移除粉紅色方形 |
| 設定三個角色顯示 | - | 創建三個同命蠱角色並排顯示 |
| 列出所有可用精靈 | - | 在 Console 顯示可用的圖片 |
