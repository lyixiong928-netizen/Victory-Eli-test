# ⚡ 立即執行 - 最簡單的方法

## 問題
Unity 開啟後沒有自動重新匯入，出現 60 個錯誤

---

## 🎯 解決方法（只需 3 步驟）

### 步驟 1: 關閉 Unity
關閉當前開啟的 Unity Editor

### 步驟 2: 執行修復腳本
在專案資料夾找到並**雙擊**：

```
執行重新匯入.bat
```

### 步驟 3: 按照提示操作
1. 選擇選項 **1**（只刪除 Temp）
2. 選擇選項 **1**（自動開啟 Unity）
3. 等待完成

---

## 📍 檔案位置

```
C:\Users\auser\Victory-Eli-test\執行重新匯入.bat
```

## 🔧 其他執行方法

### 方法 1: 使用檔案總管
1. 按 `Win + E`
2. 瀏覽到：`C:\Users\auser\Victory-Eli-test`
3. 雙擊 `執行重新匯入.bat`

### 方法 2: 使用 VS Code
1. 開啟 VS Code
2. 按 `Ctrl + ` 開啟終端機
3. 輸入：`.\執行重新匯入.bat`
4. 按 Enter

### 方法 3: 直接執行 PowerShell
1. 按 `Ctrl + ` 開啟 VS Code 終端機
2. 輸入：
```powershell
.\ForceReimport.ps1
```
3. 按 Enter

## 🆘 如果遇到問題

### 問題 1: 雙擊 .bat 檔案沒反應
**解決：** 使用 VS Code 終端機執行（方法 3）

### 問題 2: PowerShell 顯示「無法執行」
**解決：** 在 PowerShell 中先執行：
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```
然後再執行腳本

### 問題 3: 找不到檔案
**解決：** 確認您在正確的資料夾：
```powershell
cd "C:\Users\auser\Victory-Eli-test"
dir *.bat
```
