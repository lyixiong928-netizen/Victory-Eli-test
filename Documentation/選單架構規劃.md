## 📋 目前問題

1. **選單路徑不統一**：有些用 `DarkDescentDemo/`，有些在其他位置
2. **分類混亂**：「快速修復」「修復工具」「除錯工具」功能重疊
3. **命名不一致**：有些用 emoji，有些沒有
4. **優先級混亂**：`false, 0`、`false, 1` 等數字散亂

## 📝 重組計畫

### Phase 1: 快速啟動 (Quick Start)
- 合併「快速創建」和「一鍵設定」
- 統一命名格式：動詞開頭

### Phase 2: 場景設定 (Scene Setup)  
- 整合「背景設定」「顏色設定」「材質設定」
- 按功能分類，不按技術分類

### Phase 3: 動畫系統 (Animation)
- 整合「動畫測試」「動畫控制」
- 清楚區分：創建 vs 控制 vs 測試

### Phase 4: 特效系統 (Effects)
- 整合「粒子系統」「視覺效果」
- 按效果類型分類

### Phase 5: 開發工具 (Tools)
- 整合「修復工具」「診斷工具」「開發工具」
- 只保留常用功能

### Phase 6: 除錯診斷 (Debug)
- 集中所有診斷檢查功能
- 提供快速修復連結

## 🎯 命名規則

1. **主選單**：Dark Descent（統一，簡短）
2. **emoji 使用**：只在第一層級使用，保持視覺一致
3. **優先級規則**：
   - 0-99: Quick Start
   - 100-199: Scene Setup
   - 200-299: Animation
   - 300-399: Effects
   - 400-499: Tools
   - 500-599: Debug
   - 600-699: Settings

4. **命名格式**：
   - 英文為主（方便搜尋）
   - 動詞開頭（Setup、Create、Fix）
   - 簡潔明確（不超過 4 個字）
