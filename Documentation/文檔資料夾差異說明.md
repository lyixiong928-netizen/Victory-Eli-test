# 📚 文檔資料夾差異說明

## 🎯 快速理解

```
專案根目錄
│
├─ Documentation/               👈 【專案層級文檔】
│   ├─ README.md                   整個專案的總說明
│   ├─ QUICKSTART.md               開發者快速開始
│   ├─ 專案架構分析.md              架構設計文檔
│   └─ ...                         開發流程、規範等
│
└─ Assets/                      👈 【Unity 專案】
    └─ _ProjectDocs/               【遊戲層級文檔】
        ├─ 同命蠱動畫系統.md         遊戲功能說明
        ├─ 遊戲選單設置.md           遊戲系統指南
        └─ DIAGNOSTIC_REPORT.txt   Unity 技術報告
```

---

## 📖 詳細對比

### Documentation/（專案文檔）

**位置：** 根目錄  
**版本控制：** Git 追蹤  
**可見度：** GitHub 上直接可見  

**內容類型：**
- ✅ 專案說明書（README）
- ✅ 開發流程指南
- ✅ 架構設計文檔
- ✅ API 文檔
- ✅ 部署說明
- ✅ 貢獻指南

**給誰看：**
- 👥 團隊成員
- 🌍 開源貢獻者
- 📝 專案管理者
- 🔍 想了解專案架構的人

**範例內容：**
```
Documentation/
├─ README.md              ← "這是什麼專案？"
├─ QUICKSTART.md          ← "如何開始開發？"
├─ ARCHITECTURE.md        ← "專案架構是什麼？"
├─ CONTRIBUTING.md        ← "如何貢獻代碼？"
└─ DEPLOYMENT.md          ← "如何部署？"
```

---

### Assets/_ProjectDocs/（Unity 文檔）

**位置：** Unity Assets 資料夾內  
**版本控制：** Git 追蹤  
**可見度：** 需要打開 Unity 專案才看得到  

**內容類型：**
- ✅ 遊戲功能說明
- ✅ Unity 系統文檔
- ✅ 遊戲設計筆記
- ✅ 技術實作細節
- ✅ Unity 診斷報告

**給誰看：**
- 🎮 遊戲設計師
- 💻 Unity 開發者
- 🎨 美術人員
- 🎵 音效設計師

**範例內容：**
```
Assets/_ProjectDocs/
├─ 同命蠱動畫系統.md      ← "這個遊戲功能怎麼做？"
├─ 遊戲選單設置.md        ← "UI 系統如何設計？"
├─ 角色動畫規範.md        ← "動畫怎麼實作？"
└─ DIAGNOSTIC_REPORT.txt ← "Unity 診斷報告"
```

---

## 🎯 使用場景

### 📚 Documentation/ 用於：

1. **新成員加入**
   ```
   新人：「這個專案是做什麼的？」
   → 看 Documentation/README.md
   ```

2. **開始開發**
   ```
   開發者：「我要如何設置開發環境？」
   → 看 Documentation/QUICKSTART.md
   ```

3. **了解架構**
   ```
   技術主管：「專案架構設計如何？」
   → 看 Documentation/ARCHITECTURE.md
   ```

4. **GitHub 展示**
   ```
   訪客：「這專案看起來如何？」
   → GitHub 首頁自動顯示 Documentation/README.md
   ```

---

### 🎮 Assets/_ProjectDocs/ 用於：

1. **實作遊戲功能**
   ```
   開發者：「同命蠱系統怎麼實作的？」
   → 看 Assets/_ProjectDocs/同命蠱動畫系統.md
   ```

2. **設計遊戲系統**
   ```
   設計師：「遊戲選單有哪些功能？」
   → 看 Assets/_ProjectDocs/遊戲選單設置.md
   ```

3. **Unity 技術問題**
   ```
   技術人員：「Unity 有什麼問題？」
   → 看 Assets/_ProjectDocs/DIAGNOSTIC_REPORT.txt
   ```

4. **遊戲設計筆記**
   ```
   策劃：「這個關卡設計理念是什麼？」
   → 看 Assets/_ProjectDocs/關卡設計.md
   ```

## 💡 記憶技巧

### 🎨 用顏色記憶：

```
🔵 Documentation/        = 藍圖（專案整體規劃）
🎮 Assets/_ProjectDocs/  = 紅心（遊戲核心內容）
```

### 📏 用範圍記憶：

```
Documentation/           = 大範圍（整個專案）
Assets/_ProjectDocs/     = 小範圍（Unity 遊戲）
```

### 🎯 用對象記憶：

```
Documentation/           = 給程式設計師
Assets/_ProjectDocs/     = 給遊戲開發者
```

## 🌟 最佳實踐

### ✅ 應該放在 Documentation/：

- ✅ README.md（專案介紹）
- ✅ 開發環境設置
- ✅ 編碼規範
- ✅ Git 工作流程
- ✅ CI/CD 說明
- ✅ 部署指南
- ✅ API 文檔

### ✅ 應該放在 Assets/_ProjectDocs/：

- ✅ 遊戲功能說明
- ✅ 關卡設計文檔
- ✅ 角色設定
- ✅ UI/UX 設計說明
- ✅ 動畫實作筆記
- ✅ Unity 特定技術文檔
