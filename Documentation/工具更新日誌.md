# 🛠️ 工具更新日誌

## 2026-01-15

### ✅ 新增工具

#### 1. **一鍵動畫設定 (OneClickAnimation.cs)**
- 路徑：`DarkDescentDemo/🎬 一鍵動畫設定`
- 功能：
  - 視覺化介面設定動畫速度
  - 滑桿調整幀率（1-10 FPS）
  - 預設按鈕：慢(1秒)、中(0.5秒)、快(0.2秒)
  - 自動檢測並添加所需組件
  - 一鍵清除動畫設定
- 簡化複雜流程，降低使用門檻

#### 2. **精靈切片診斷器 (SpriteDiagnosticTool.cs)**
- 路徑：`DarkDescentDemo/診斷工具/🔍 精靈切片診斷器`
- 功能：
  - 檢查精靈檔案存在性
  - 驗證 TextureImporter 設定
  - 顯示 Sprite Sheet 詳細資訊
  - 視覺化預覽每個切片
  - 測試精靈搜尋功能
  - 單獨測試每個精靈顯示
- 用於診斷精靈載入問題

#### 3. **雙幀/三幀動畫測試工具 (QuickTwoFrameAnimation.cs)**
- 路徑：
  - `DarkDescentDemo/動畫測試/🎬 建立雙幀動畫測試 (1秒間隔)`
  - `DarkDescentDemo/動畫測試/🚀 建立三幀動畫測試 (0.5秒間隔)`
  - `DarkDescentDemo/動畫測試/📊 顯示當前動畫資訊`
- 功能：
  - 快速創建基礎動畫測試
  - 詳細的 Console 日誌輸出
  - 自動調整物件位置與大小
  - 提高可見性（sortingOrder: 10）
  - 自動聚焦並高亮物件

### 🔧 修復問題

#### 1. **選單衝突**
- 問題：SceneValidator 和 QuickSceneValidator 使用相同選單路徑
- 解決：
  - SceneValidator → `Dark Descent/🔍 場景驗證/完整驗證`
  - QuickSceneValidator → `Dark Descent/🔍 場景驗證/快速檢查`

#### 2. **精靈命名規範**
- 問題：AutoSliceSprite 使用自訂名稱（Skeleton, CursedGirl, DarkCreature）
- 解決：統一使用 Unity 標準格式（`建立影像 同命蠱_0`, `_1`, `_2`）

## 核心理念

**禎圖為解決之道** - 精靈切片是動畫系統的基礎，必須確保：
- 正確的切片命名
- 準確的切片位置
- 可靠的載入機制

所有工具設計都圍繞這三個核心目標。
