## 🎯 問題概述

### 桃色方塊現象
當場景中出現**桃色（洋紅色）方塊**時，表示：
- `SpriteRenderer.sprite = null`
- Unity 顯示 `Color(1, 0, 1, 1)` 作為缺失資源的 Debug 提示

### 物理抖動問題
角色自由落體時出現抖動，原因：
- Rigidbody2D 參數未優化
- 使用內建重力與自定義重力衝突
- Interpolation 未啟用

### 階層結構錯誤
子物件有獨立物理行為：
- 子物件錯誤添加了 Rigidbody2D
- 父子物件都有 SpriteRenderer 導致衝突

## 🛠️ 工具清單

### 1. OneClickFix.cs - 一鍵完整修復 ⭐ 推薦

**選單位置：** `DarkDescentDemo → 🔧 一鍵完整修復（解決桃色方塊）`

**功能：**
- ✅ 自動載入精靈圖片
- ✅ 指定第一張精靈到 SpriteRenderer
- ✅ 填充 animationSprites 陣列
- ✅ 啟用鬼影拖尾效果
- ✅ 自動儲存場景

**使用時機：**
- 場景中出現桃色方塊
- FallingCharacter 沒有顯示正確圖片
- 動畫沒有播放

**注意事項：**
- ⚠️ 必須在 Edit Mode 執行（停止播放）
- ⚠️ 工具會自動檢測並提示

---

### 2. FixPinkSquares.cs - 修復桃色方塊

**選單位置：** `DarkDescentDemo → 修復工具 → 🎨 修復桃色方塊（自動指定圖片）`

**功能：**
- 自動找到 FallingCharacter
- 載入「建立影像 同命蠱.png」的所有切片
- 指定精靈到 SpriteRenderer 和動畫陣列

**輔助功能：**
- `📋 檢查 FallingCharacter 狀態` - 診斷問題
- `🔍 列出所有精靈圖片` - 確認圖片切片

---

### 3. OptimizeRigidbody2D.cs - 優化物理參數

**選單位置：**
- `DarkDescentDemo → 修復工具 → ⚙️ 優化 Rigidbody2D 參數`
- `DarkDescentDemo → 快速創建 → 📋 Rigidbody2D 手動調整指南`

**自動優化設定：**
```csharp
Gravity Scale = 0        // 關閉內建重力
Linear Drag = 0          // 無阻力
Interpolate = Interpolate // 平滑移動
Freeze Rotation Z = ✓    // 凍結旋轉
```

**手動調整步驟：**
1. 選中 FallingCharacter
2. 找到 Rigidbody 2D 組件
3. 按指南調整 4 個參數
4. 按 Play 測試

---

### 4. RebuildFallingCharacter.cs - 重建結構

**選單位置：** `DarkDescentDemo → 修復工具 → 🔄 重建 FallingCharacter 結構`

**功能：**
- 清理父物件的 SpriteRenderer（如有）
- 清理子物件的物理組件（Rigidbody2D、Collider2D）
- 確保子物件 localPosition = (0, 0, 0)
- 設定正確的父子關係（worldPositionStays = false）

**使用時機：**
- 子物件有獨立的自由落體
- 階層結構混亂
- 物理行為異常

**正確結構：**
```
FallingCharacter (父物件)
├── DarkDescentController
├── CharacterAnimator
├── ParticleEffectManager
├── Rigidbody2D ✅
└── CharacterSprite (子物件)
    └── SpriteRenderer ✅
    └── (無物理組件)
```

---

### 5. CreateFallingCharacter.cs - 創建/尋找角色

**選單位置：**
- `GameObject → DarkDescent → 創建 FallingCharacter`
- `DarkDescentDemo → 快速創建 → 🎭 創建 FallingCharacter`
- `DarkDescentDemo → 快速創建 → 🔍 尋找 FallingCharacter`

**功能：**

- CharacterAnimator（動畫控制）
- ParticleEffectManager（粒子效果）
- Rigidbody2D（物理模擬）
- 子物件 CharacterSprite（視覺渲染）

## ❓ 常見問題

### Q1: 執行工具時出現「This cannot be used during play mode」錯誤？

**原因：** 在 Play Mode 執行了編輯器工具

**解決：**
1. 按 Stop ⏹️ 停止播放
2. 重新執行工具
3. 修復完成後再按 Play ▶️

---

### Q2: 執行「一鍵修復」後還是桃色方塊？

**可能原因：**
1. 精靈圖片未正確切片
2. 圖片路徑錯誤

**解決：**
1. 執行「🔍 列出所有精靈圖片」確認切片
2. 執行「✂️ 自動切片精靈圖」
3. 重新執行「一鍵修復」

---

### Q3: 角色落下時還是抖動？

**檢查清單：**
- [ ] Gravity Scale = 0
- [ ] Linear Drag = 0
- [ ] Interpolate = Interpolate
- [ ] Freeze Rotation Z = ✓

**解決：**
- 執行「⚙️ 優化 Rigidbody2D 參數」自動修正
- 或按「📋 手動調整指南」逐項檢查

---

### Q4: 子物件有獨立的自由落體？

**原因：** 子物件有自己的 Rigidbody2D

**解決：**
1. 執行「🔄 重建 FallingCharacter 結構」
2. 工具會自動清理子物件的物理組件

**正確設定：**
- 父物件 FallingCharacter：有 Rigidbody2D ✅
- 子物件 CharacterSprite：只有 SpriteRenderer ✅

---

### Q5: 找不到 FallingCharacter？

**搜尋方法：**
1. 執行「🔍 尋找 FallingCharacter」
2. 工具會搜尋包含隱藏物件
3. 找到後會自動選中並高亮

**手動尋找：**
- 在 Scene View 中 Zoom in/out
- FallingCharacter 預設位置：(0, 15, 0)

**創建新的：**
- 執行「🎭 創建 FallingCharacter」
- 自動配置所有組件

---

### Q6: Ghost Trail 沒有出現？

**原因：** SpriteRenderer.sprite = null

**解決：**
1. 執行「一鍵修復」載入精靈圖片
2. 確認 CharacterAnimator 的 enableGhostTrail = true
3. 檢查 Console 是否有「sprite is null!」錯誤

**正確配置：**
```csharp
enableGhostTrail = true
ghostSpawnInterval = 0.05f  // 每 0.05 秒生成一個鬼影
ghostLifetime = 0.8f        // 鬼影持續 0.8 秒
```

## 🎯 最佳實踐

### ✅ 推薦工作流程

1. **新場景設置**
   ```
   創建 FallingCharacter → 一鍵修復 → 優化物理參數 → 測試
   ```

2. **修復現有問題**
   ```
   診斷問題 → 使用對應工具 → 驗證結果
   ```

3. **手動微調**
   ```
   自動修復 → 手動調整細節 → 最終測試
   ```

### ⚠️ 注意事項

1. **工具執行順序**
   - 先修復結構（重建階層）
   - 再修復資源（載入精靈）
   - 最後優化參數（物理設定）

2. **Play Mode 限制**
   - 所有編輯器工具必須在 Edit Mode 執行
   - 工具會自動檢測並提示

3. **場景保存**
   - 工具會自動標記場景為 Dirty
   - Edit Mode：自動保存
   - Play Mode：需要手動保存（退出 Play 後）
