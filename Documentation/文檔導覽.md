## ⚡ 快速查找

### 我想要...

**學習粒子系統**
→ [粒子系統基礎教學.md](粒子系統基礎教學.md)

**修復粉紅方塊**
→ Material 沒設定，看粒子系統基礎教學第二步

**創建場景**
→ Dark Descent 選單 → 創建場景

**切換角色**
→ 3 張圖片拖入 Animation Sprites，勾選 Use Sprites As Characters

**解鎖粒子系統**
→ Dark Descent 選單 → 解鎖粒子 (U)

**看粒子狀態**
→ Dark Descent 選單 → 顯示粒子狀態

**重置遊戲**
→ 按 R 鍵

**暫停遊戲**
→ 按 F6 或 Dark Descent 選單 → 暫停

## 💡 重要提醒

### 必須記住的事

1. **粒子系統一定要設 Material**
   - 沒設 = 粉紅方塊或看不見
   - 用 Default-Particle 最簡單

2. **先手動設置，再用腳本**
   - 理解參數意義
   - 建立直覺感

3. **3 張圖 = 3 個角色**
   - 不是動畫循環
   - 是靜態角色切換

4. **快捷鍵**
   - R = 重置
   - D = Debug 資訊
   - M = 粒子監控
   - U = 解鎖粒子
   - F5 = 播放
   - F6 = 暫停
   - 1/2/3 = 切換角色（如果用 SimpleCharacterSwitcher）

## 🆘 需要幫助？

### 按優先順序檢查

1. **看不到東西？**
   - 檢查 Material 設定
   - 檢查物件是否啟用
   - 檢查 Layer 和 Sorting Order

2. **粒子不動？**
   - 檢查 Emission > Rate over Time
   - 檢查粒子是否播放（Play）
   - 看粒子系統基礎教學

3. **編譯錯誤？**
   - 看 UNITY_ERROR_FIX.md
   - 檢查 Console 錯誤訊息

4. **不知道怎麼做？**
   - 看對應的教學文檔
   - 使用簡化選單（Dark Descent）
