# 粒子系統基礎教學

## 第一步：創建粒子系統

1. **右鍵 Hierarchy → Effects → Particle System**
2. 命名為 `TestParticle`
3. 現在你看到白色粒子在噴射

---

## 第二步：設置材質（必做！）

### 為什麼要設材質？
- 沒有材質 = 粉紅色方塊或看不見
- 材質決定粒子的外觀

### 怎麼設？

1. **選擇粒子物件**
2. **找到 Renderer 模塊**（在 Inspector 最下面）
3. **Material 欄位**要設置：

#### 選項 A：使用預設材質（最簡單）
```
Material: Default-Particle
```
Unity 內建，白色圓形粒子

#### 選項 B：創建自己的材質
1. 右鍵 Project → Create → Material
2. 命名 `MyParticleMat`
3. Shader 改成 `Particles/Standard Unlit`
4. 拖到粒子的 Material 欄位

---

## 第三步：理解 5 個核心參數

### 1. Emission（發射率）
```
Rate over Time: 10
```
- 10 = 每秒 10 個粒子（稀疏）
- 50 = 每秒 50 個粒子（密集）
- 100 = 每秒 100 個粒子（很密）

### 2. Start Lifetime（壽命）
```
Start Lifetime: 2.0
```
- 1 秒 = 快速消失
- 3 秒 = 停留較久
- 5 秒 = 飄很遠

### 3. Start Speed（速度）
```
Start Speed: 5
```
- 1 = 慢慢飄
- 5 = 正常速度
- 10 = 快速噴射

### 4. Start Size（大小）
```
Start Size: 0.3
```
- 0.1 = 小點點
- 0.5 = 正常大小
- 2.0 = 大顆粒

### 5. Start Color（顏色）
```
Start Color: 白色/紅色/自訂
```
點擊色塊選顏色

---

## 第四步：Shape（形狀）最重要！

### Cone（圓錐）- 向下噴
```
Shape: Cone
Angle: 25°
Radius: 0.3
```
用途：墜落效果、噴泉

### Sphere（球形）- 四散
```
Shape: Sphere  
Radius: 0.5
```
用途：爆炸、擴散

### Box（方形）- 區域
```
Shape: Box
Scale: (1, 1, 1)
```
用途：下雨、範圍效果

## 實作練習：做一個墜落碎片效果

### 目標
模擬角色墜落時掉落的碎片

### 參數設定
```
【Main 模塊】
Start Lifetime: 1.5
Start Speed: 3
Start Size: 0.15
Start Color: 灰白色

【Emission】
Rate over Time: 30

【Shape】
Shape: Cone
Angle: 20
Radius: 0.2

【Renderer】
Material: Default-Particle
Render Mode: Billboard
```

### 測試
1. 按 Play
2. 應該看到白色小點向下噴射
3. 調整參數看效果變化

## 常見問題

### Q: 看不到粒子？
A: 檢查：
1. Renderer 的 Material 有設嗎？
2. Emission 的 Rate over Time > 0？
3. 攝影機能看到這個位置嗎？

### Q: 粒子是粉紅色方塊？
A: Material 沒設定，拖一個 Default-Particle 進去

### Q: 粒子太少/太多？
A: 調整 Emission → Rate over Time

## 進階：添加腳本控制（選修）

當你手動設定都熟悉後，再用腳本：

```csharp
ParticleSystem ps = GetComponent<ParticleSystem>();

// 播放
ps.Play();

// 停止
ps.Stop();

// 改發射率
var emission = ps.emission;
emission.rateOverTime = 50;
```

做完一個粒子效果後，檢查：

- [ ] Material 有設定嗎？

- [ ] 壽命合理嗎？（1-5秒）
- [ ] Shape 符合需求嗎？
- [ ] 按 Play 測試過嗎？
