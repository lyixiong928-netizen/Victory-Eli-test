# 分離精靈墜落效果使用指南

## 📖 功能說明

讓 CharacterSprite 底下的多張幀圖（精靈切片）能夠**分開**並**各自自由落體墜下**，每個精靈都有獨立的物理效果、旋轉、散開方向和淡出效果。

## 🎬 效果展示

當觸發分離效果時：
1. ✅ 原本的 CharacterSprite 會隱藏
2. ✅ 每張精靈圖片會複製出來成為獨立物件
3. ✅ 每個精靈有自己的 Rigidbody2D，獨立墜落
4. ✅ 隨機的水平散開力和旋轉速度
5. ✅ 漸進淡出效果
6. ✅ 可選的鬼影拖尾效果

## 🚀 快速設定（推薦）

### 方法一：使用一鍵設定工具

1. 打開 Unity 編輯器
2. 確保已有 **FallingCharacter** 物件在場景中
3. 選單：**DarkDescentDemo → 快速創建 → ✨ 添加分離精靈墜落效果**
4. 完成！所有設定自動配置

### 方法二：手動添加

1. 選中場景中的 **FallingCharacter** 物件
2. 在 Inspector 點擊 **Add Component**
3. 搜尋並添加 **SeparateSpritesFall** 腳本
4. 在 Inspector 中設定參數（見下方詳細說明）

## 🎮 使用方法

### 基本操作

1. **啟動遊戲**：按下 Unity 的 Play 按鈕
2. **角色開始墜落**
3. **觸發分離**：按下 **Space 鍵**（預設）
4. **觀察效果**：精靈會分離並各自墜落

### 自動觸發（可選）

如果想要在墜落到一半時自動觸發：
1. 選中 FallingCharacter
2. 在 Inspector 找到 **SeparateSpritesFall** 組件
3. 勾選 **Auto Trigger At Halfway**

## ⚙️ 參數說明

### 精靈設定

| 參數 | 說明 | 預設值 |
|------|------|--------|
| **Sprites To Separate** | 要分離的精靈圖片陣列 | 自動載入「建立影像 同命蠱.png」的切片 |

### 物理參數

| 參數 | 說明 | 預設值 | 建議範圍 |
|------|------|--------|----------|
| **Gravity Scale** | 每個分離精靈的重力倍數 | 1.5 | 0.5 - 3.0 |
| **Horizontal Force Range** | 分離時的水平散開力度 | 3.0 | 1.0 - 5.0 |
| **Rotation Speed Range** | 分離時的旋轉速度（度/秒）| 180 | 0 - 360 |
| **Separated Scale** | 分離後精靈的縮放倍數 | 1.5 | 0.5 - 3.0 |

### 視覺效果

| 參數 | 說明 | 預設值 |
|------|------|--------|
| **Fade Out Duration** | 淡出持續時間（秒）| 3.0 |
| **Separated Color** | 分離精靈的顏色 | 白色 |
| **Enable Ghost Trail** | 是否啟用鬼影拖尾 | 是 |

### 觸發設定

| 參數 | 說明 | 預設值 |
|------|------|--------|
| **Trigger Key** | 觸發分離的按鍵 | Space |
| **Auto Trigger At Halfway** | 是否在墜落到一半時自動觸發 | 否 |

## 🔧 進階功能

### 程式化觸發

可以從其他腳本中觸發分離效果：

```csharp
// 取得組件
SeparateSpritesFall separateScript = GetComponent<SeparateSpritesFall>();

// 觸發分離
separateScript.TriggerSeparation();

// 重置（可再次觸發）
separateScript.ResetSeparation();
```

### 自訂精靈陣列

如果不想使用預設的「建立影像 同命蠱.png」：

1. 在 Inspector 中展開 **Sprites To Separate** 陣列
2. 設定陣列大小（Size）
3. 將想要分離的精靈拖入陣列中

### 修改觸發按鍵

在 Inspector 中找到 **Trigger Key**，點擊下拉選單選擇其他按鍵：
- **E** 鍵：互動感
- **F** 鍵：功能鍵
- **Mouse0**：滑鼠左鍵
- **Q** 鍵：技能鍵

## 📋 腳本組成

此功能包含 4 個類別（全在同一個檔案中）：

1. **SeparateSpritesFall**：主控制器
2. **SeparatedSpriteFade**：淡出效果
3. **SeparatedSpriteGhost**：鬼影拖尾
4. **GhostFade**：鬼影淡出

## 🐛 常見問題

### Q: 按 Space 沒反應？
**A:** 檢查以下項目：
1. 確認遊戲正在運行（Play 模式）
2. 檢查 Console 是否有警告訊息
3. 確認 **Sprites To Separate** 陣列有設定精靈

### Q: 精靈沒有墜落？
**A:** 檢查 **Gravity Scale** 是否大於 0

### Q: 精靈一觸發就消失？
**A:** 增加 **Fade Out Duration** 的數值

### Q: 想要更多/更少的精靈分離？
**A:** 修改 **Sprites To Separate** 陣列的內容

### Q: 如何讓精靈分離得更分散？
**A:** 增加 **Horizontal Force Range** 的數值

### Q: 如何移除此效果？
**A:** 選單：**DarkDescentDemo → 快速創建 → 🔄 重置分離精靈效果**

## 📝 技術細節

### 物理實現
- 使用 Unity 的 **Rigidbody2D** 組件
- 每個分離精靈有獨立的物理身體
- 隨機初始速度和角速度
- 自動應用重力和空氣阻力

### 性能考量
- 分離的精靈會自動在淡出後銷毀
- 鬼影效果有生命週期限制
- 適合用於短暫的視覺特效

### 兼容性
- ✅ 與 **DarkDescentController** 完全兼容
- ✅ 與 **CharacterAnimator** 共存無問題
- ✅ 與粒子系統協同工作

## 🎯 實戰範例

### 場景：角色墜落到深淵

```
效果流程：
1. 角色開始墜落（0 秒）
2. 墜落到一半時自動觸發分離（約 1-2 秒）
3. 身體分解成多個精靈，各自旋轉墜落
4. 每個精靈帶著鬼影拖尾
5. 3 秒後完全淡出消失
```

**設定：**
- Auto Trigger At Halfway: ✅
- Gravity Scale: 1.5
- Enable Ghost Trail: ✅
- Fade Out Duration: 3.0
